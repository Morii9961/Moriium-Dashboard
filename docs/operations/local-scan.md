# 本机仓库扫描

P7 的 L2：在本机实例里登记几个目录，导入时一键找出这些仓库里 Dashboard 还没有的状态快照。找到的快照和手动选择的文件一样，先预览、再由你确认导入；扫描本身不写入任何快照。

## 用法

1. 设置 → 本机仓库，填一个目录的绝对路径，例如放所有项目仓库的那一层目录。最多 20 个。
2. 导入 → 从本机仓库查找。每个登记的目录本身和它的下一层子目录里，只读固定的 `docs/status/project-status.json`。
3. 已经导入过的同一份快照、项目没有登记的快照会被跳过；其余进入导入列表，照常检查、预览和确认。

## 边界

- 只在本机实例出现。开启登录认证（部署到 VPS）时没有这个接口，设置页和导入对话框也不显示入口。
- 登记的目录保存在数据目录的 `local-repositories.json`，不进数据库、业务导出包或日志；恢复到新实例时不会带过去。
- 不跟随链接或隐藏目录，不往更深的层级找；单个文件超过 1 MiB 跳过；一次最多找 100 份。
- 只读文件，不运行仓库里的任何东西，也不访问网络。
