## 启动更新后的本机版本

1. 合并完成后使用最新 `main`，运行 `pnpm build`。
2. 关闭旧 Dashboard 服务后，从原来的启动环境启动；换了终端时，把 `MORIIUM_DASHBOARD_DATA` 指向**原来的正式数据目录**，再运行 `pnpm server`。精确私有路径与启动命令仍在本机被忽略的 `screenshots/p4-6-real/data-location.md`，不要把该文件或数据库提交到公开仓库。
3. 启动已有库时，现有机制先创建迁移前备份，再执行待执行迁移。P5 新增 `0008_focus`、`0009_tasks`、`0010_works`；如果旧实例还未执行 P4 迁移，也会一并执行。确认旧有六项目和历史仍在，再开始试用。
4. 打开 `http://127.0.0.1:5180`，手动导入新的 `docs/status/project-status.json`。若出现空库，先核对数据目录，不重复导入或覆盖原文件。

本轮没有启动正式实例。继续接手时先核对 GitHub 合并状态、工作区和实际实例版本，不把前端构建完成当作正式库已经更新。
