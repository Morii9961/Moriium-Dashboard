# 设计决定记录

每做出一个具体的设计决定，在最上面加一条。已记录的决定直接沿用，不重新讨论。推翻旧决定时，新增一条并写明替代了哪一条，不要直接改旧条目。

条目格式：

```
## YYYY-MM-DD · 标题

- 决定：做了什么选择。
- 理由：为什么。
- 影响：涉及哪些区域、组件或 token。
- 依据：看过的参考、读过的 Skill、测量或截图（只写实际看过的）。
- 状态：试验 / 定稿 / 已被替代（替代者：…）
```

## 2026-10-12 · P3 导入与历史

- 决定：
  - **预览在服务端做**：导入对话框把文件（base64）发给 `POST /api/imports/check`，由服务端用协议包检查、定位、对比，不写入；确认时 `POST /api/imports` 从头再检查一遍。04 第 3 节写的是「前端先跑一遍」，改成服务端的理由是：本机服务响应是即时的；定位和对比本来就要查数据库；前端不必再打包校验器。写入时服务端复核这一条不变。
  - **同一批里同一项目多份**：只有最晚的一份显示为「将成为最新」，其余显示「比同一批里的另一份早，只进入历史」，写入结果也这样记。
  - **问题说明只有中文**：协议包生成的问题说明和「复制给 Agent 的修复说明」是中文，日文、英文界面里也显示中文，并标 `lang="zh-Hans"`。修复说明本来就是给 Agent 的，中文没有问题；界面上的说明要不要翻成日文和英文，由 Morii 决定。
  - **回收站**：删除是软删除，可以恢复；同一时刻已有有效快照时拒绝恢复。04 第 10 节「30 天后在设置里永久删除」这次没做，自动删数据的风险留到 P5 之前再定。
  - **导出**：自写只用存储方式的 ZIP（零依赖）；`snapshots/` 只放有效快照，回收站里的和被替换的版本放 `snapshots-archive/`，这样「只导出快照原文」的包可以直接再导入。
  - **历史的时间带**：至少显示 14 天，每份快照一个刻度，当前那份用雾蓝；只表达报告的疏密。
- 理由：04 第 3 到 12 节；实现中的取舍见上。
- 影响：`apps/server/src/{imports,snapshots,history,export,zip}.ts`、`apps/web/src/app/{ImportDialog,History,projectPages}.tsx`。
- 依据：端到端测试 26 个（重复、冲突、旧快照、各类非法文件、撤销、历史、导出再导入）；临时数据目录里导入了五个项目的真实快照和 Dashboard 自己的快照，并从 Git 历史补导了 4 份旧快照。
- 状态：定稿（问题说明的翻译待 Morii 决定）

## 2026-10-12 · P2.2 设计基线：token、字体、主题、三语、招牌元素

- 决定：
  - **token**：`apps/web/src/design/tokens.ts` 是唯一来源，`pnpm tokens` 生成静态的 `src/styles/tokens.css`（测试检查没有过期）。颜色按上面几条定稿；间距以 4 为基数（4 到 96）；圆角 6 / 10 / 14；字号 12、13、15、17、22、28、36，刊头大标题 `clamp(36px, 6.2vw, 76px)`；动效缓动统一 `cubic-bezier(0.16, 1, 0.3, 1)`，时长 180 / 280 / 520ms。
  - **字体**：全部来自 npm 包，由 Vite 打进构建产物，运行时不请求外部地址（实测外部请求 0）。中日文按 unicode-range 分片。设计基线页同时展示三种文字，首次打开下载约 2.2 MB 字体，之后由浏览器缓存；P2.3 起量一次只用中文的页面。署名和许可见 `THIRD_PARTY_NOTICES.md`（含 MiSans 署名）。
  - **主题**：跟随系统 / 浅色「雾」/ 深色「夜」，选择存在浏览器本地；`public/theme-init.js` 在首帧前设置，避免闪烁（同源外部脚本，符合严格 CSP）。切换时新主题从按钮处圆形揭开（View Transitions，520ms），减少动画偏好下直接切换。这推翻了 02 第 14 节「主题切换不做动画」，理由是 Morii 要求更有设计感，而且这个动画只在用户主动切换时出现一次。
  - **三语**：ICU 消息（`intl-messageformat` 12.1.2，BSD-3-Clause），中文是源语言；`<html lang>` 随界面语言切换，字体栈按 lang 选。测试检查三份文案键和参数一致、都能解析、中文空格、日文敬体、英文没有感叹号。文案约定写在 `docs/copy-conventions.md`。
  - **招牌元素「线路总图」**：把阶段轴放大成一张地铁线路图，每个项目一条线，停在当前阶段；站是横跨所有线的胶囊，按走得最远的排在上面。首次出现时线条依次画出，悬停或聚焦一条线时其余退到背景，点击跳到对应的项目长条并展开。它是 02 第 13 节「招牌时刻：阶段轴」的延伸，全站只此一处；P4 的概览会用它做首屏。
  - 刊头标题由数据生成，例如「6 个项目在路上，40 件待确认。」，不写口号。

- 影响：`apps/web/src/{design,styles,theme,i18n}`；样张页改为设计基线页；P2.3 外壳直接使用这些模块。
- 依据：`pnpm verify`；1440 / 1210 / 375 宽度、浅色深色、中日英截图；字体下载实测。
