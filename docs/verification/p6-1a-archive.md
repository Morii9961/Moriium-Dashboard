# P6.1a · 导出包容器校验

2026-10-16，Morii 允许提前做 P6 工程准备，P4/P5 的真实试用和产品验收继续待完成。恢复工作拆成容器校验与恢复命令两个依赖工作包，分别审阅；本包不添加恢复入口或修改正式数据。

`restore/archive.ts` 只接受现有导出器生成的 UTF-8、store-only ZIP 子集。校验本地头与中央目录、CRC、连续偏移及边界；拒绝加密、压缩、ZIP64、额外记录、重复及大小写别名、路径穿越。全程在内存读取，不解压文件到磁盘。包最多 256 MiB / 10,002 项；元数据、快照和封面分别限量。

元数据 JSON 拒绝重复键（含 Unicode 转义别名）、非有限数字、超过 64 层的结构、非法 UTF-8 和疑似令牌（含字符串转义后的形态）。错误只返回固定代码，不回显包内文字。

本包的五项测试覆盖写入器往返、名称冲突、头部与 CRC 损坏、尺寸及项目数上限、JSON 歧义。完整恢复工作区的联合验证记录另见后续 P6.1b 记录；本 PR 的实际提交以 GitHub Windows / Linux CI 为准，不将未提交的后续代码算成本包交付。

原理参考 [PKWARE APPNOTE 6.3.10 §4.3–4.4](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)。这只保证结构完整性，不是对导出包来源的密码学认证。没有新增依赖、HTTP 接口、数据库迁移或界面；状态快照未自动更新或导入。
