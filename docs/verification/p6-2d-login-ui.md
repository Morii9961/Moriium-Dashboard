# P6.2d · 登录页

2026-10-17，分支 `claude/p6-login-ui`，堆叠于 P6.2c（#36）。设计决定见 [design-decisions](../design-decisions.md) 同日条目。

## 行为

- 服务端未开启认证时，`/api/auth/session` 回答本机模式，界面和以前一样，不出现登录页。
- 开启后先查询会话。未登录只显示登录页，应用外壳、数据请求和服务横幅都不挂载；连不上服务时照常显示应用，由原有横幅说明。
- 任何接口返回 `unauthenticated` 时，客户端发出事件，登录门回到登录页并显示「登录已结束」。
- 设置页在已登录时显示账户、到期时间、退出登录和退出所有设备。

## 检查

在临时目录建虚构账户和空业务库，以开启认证的配置在 5190 端口启动，检查后停止并删除临时数据；没有使用真实数据或正式实例。

- 深色桌面：登录页渲染、错误口令提示、口令清空且焦点回到口令框、`aria-invalid` 与 `aria-describedby` 指向提示。
- 正确登录后进入概览；刷新设置页仍保持登录；账户一组显示；退出后回到登录页，`/api/projects` 返回 401。
- 浅色 375px：中文、日文、英文三种文案不溢出；锁定后显示「15 分钟」；切换语言时提示随之翻译，焦点不被抢走。
- 纯键盘：打开页面焦点在账户框，Tab 到口令，Enter 提交。

`pnpm verify` 通过：387 项测试、类型检查、三语文案检查（键、参数、中文空格、日文敬体、英文无感叹号）与公开树审计（370 个文件），11 条既有提醒。
