# P5.3 · 任务与快照来源

手动任务有标题、输入语言、项目、截止日期和待办/进行中/完成/放弃状态。由下一步转入的任务在服务端复制原条目，绑定确切快照；来源不可改，仍开放的相同来源不能重复转入。报告中消失只产生提示，不自动完成任务。

- `pnpm verify`：318 个测试、类型和公开树审计通过；当时为 13 个提醒（11 个既有提醒，另两个多余非空断言已在 P5.4 清理）；生产构建通过。
