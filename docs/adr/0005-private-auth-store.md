# 0005 · 独立认证库与登录底层

- 日期：2026-10-17
- 状态：工程准备采用，尚未接入正式服务
- 范围：P6.2a；不代替正式登录启用或 VPS 部署授权

## 决定

1. 仍使用单个 Node 进程与 Node SQLite。在明确指定的数据目录里使用独立 `auth.sqlite` 保存账户哈希、会话摘要、限速桶和登录事件。业务库保持结构 10，不新增业务迁移；业务导出、恢复和日备份不携带认证资料。认证库损坏或缺少账户时必须拒绝认证，未来的服务接入不能回落为免登录。
2. 认证库没有默认路径。仅接受仓库外、同步目录外的绝对文件路径；解析父目录后检查，拒绝目录或文件链接，不在已有业务库里初始化认证表。Linux 文件申请 `0600`，父目录不能允许组或其他用户写入；Windows 依赖父目录 ACL。认证库只认自己的固定表和版本；其迁移独立于业务迁移。
3. 沿用规划的 scrypt，异步调用 Node crypto。版本 1 固定 `N=131072,r=8,p=1`，16 字节随机盐、32 字节派生值，`maxmem=256 MiB` 容纳工作区开销；不从输入读取成本。只保存规范编码的版本、盐和派生值，恒定时间比较。调整成本必须改变编码版本。口令取 15 个 Unicode 码点起、最多 1024 UTF-8 字节，不截断、去空格或做 Unicode 规范化；拒绝不完整代理字符及纯空白。账户名只允许小写字母起始和 ASCII 字母、数字、点、下划线、连字符，最长 64。
4. 登录核验服务每进程创建一次，同一服务最多一项 scrypt 核验在途。进入异步核验前在事务里预留限速次数：单账户桶 10 次 / 15 分钟，全局桶 60 次 / 15 分钟。单账户应用的所有输入用户名共用账户桶，不能换用户名绕过；正确登录只清账户桶，不清全局桶。限速桶持久化，拒绝请求不延长窗口；每个桶每窗口最多写一次限速事件。
5. 会话用 32 字节随机值，库中只留 SHA-256 摘要。登录每次生成新会话并撤销请求携带的旧会话；最多保留 5 个，绝对上限 24 小时、空闲上限 2 小时，每分钟至多触碰一次活动时间。服务端校验和失效，不能只依赖浏览器。口令修订变化、退出、撤销全部和时钟回拨均使相应会话失效。
6. cookie 固定 `__Host-moriium_session`，`Path=/; HttpOnly; Secure; SameSite=Strict`，不设 Domain。只供后续 HTTPS 接入，当前本机服务没有读取或签发它。未来绑定仍须保留 Host / Origin / 自定义写请求头防护，所有业务接口和数据页面默认需要会话；不能因 cookie 解析失败而放行。
7. 登录事件只存固定时间与枚举，最多 1000 条，不存请求的用户名、口令、原始会话或私有路径。HTTP 接入时再向服务日志输出经可信代理配置确认的来源，供 fail2ban 使用；本包不声称已接入 fail2ban、HTTP、口令设置命令或登录页面。

## 依据与代价

[Node 24.15 crypto](https://nodejs.org/download/release/v24.15.0/docs/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback) 提供异步 scrypt 与 timingSafeEqual；[OWASP 口令存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#scrypt) 给出采用的 scrypt 成本下限。[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) 支持随机会话标识、登录时轮换、服务端超时和安全 cookie；本项目的具体超时与限速数值是工程初始选择，真实使用后可调整。

独立认证库增加一个私有文件，但可使完整业务包天然不包含登录状态，不需要过滤业务 SQL 备份。认证数据的单独备份、重置口令、可信代理来源和系统日志格式仍需后续操作工具与部署准备补齐。没有新增依赖、第二个进程或外部服务。
